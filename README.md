# Spatial-Flow-Simulation

空間／車流／人流的互動式模擬小專案。每個子目錄是獨立的靜態網頁（`index.html` + `main.js` + `style.css`），直接用瀏覽器開即可；需要存檔或雲端執行時再加 `server.py`。

| 專案 | 說明 |
|---|---|
| [Traffic-Light](Traffic-Light/) | 路口號誌編輯器：鋪路、設號誌與時相、跑車流並偵測衝突 |
| [Indoor-Pedestrian-Flow](Indoor-Pedestrian-Flow/) | 室內人流模擬：自由擺放牆、障礙、入出口、吸引物與地面標線，比較標線對駐足與動線的影響 |
