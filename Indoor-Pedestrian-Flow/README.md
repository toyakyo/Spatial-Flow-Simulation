# Indoor-Pedestrian-Flow 室內人流模擬器

範例題目：**台南火車站大廳的公共鋼琴，地面有沒有畫標線，會不會影響人潮駐足與流動？**

## 執行

```bash
python server.py        # http://localhost:8000（含場景存取 API）
```

也可以直接用瀏覽器開 `index.html`（只是沒有「存到伺服器」按鈕，存取走 JSON 檔下載／上傳）。

無畫面批次（Node，雲端用）：

```bash
node headless.js                          # 範例場景，標線 無／有 各跑一次
node headless.js --n 2000 --seeds 5       # 2000 人、連跑 5 個種子取平均
node headless.js scenes/xxx.json --json out.json
```

## 能放什麼

| 工具 | 作用 |
|---|---|
| 牆／柱子／障礙物 | 實體，擋路；人會繞開、貼牆會被推開 |
| 入口 | 人在這裡出生。可設權重與「去向」（指定某出口，或依權重任一出口）→ 決定人流方向 |
| 出口 | 人走到這裡離場 |
| 吸引物（鋼琴） | 路過者進入注意半徑時抽籤，依「停下機率」決定要不要停，停留秒數可調 |
| 駐足線區 | 地面標線：守規矩的駐足者站進區內較空的位置；守規矩的路過者繞開（路徑成本 ×4） |
| 通行帶 | 地面標線：守規矩的路過者偏好走帶內（成本 ×0.6），駐足者不站帶內 |

左欄可設總人數（100／300／500／1000／2000／自訂）、進場時間、隨機種子、標線總開關與**遵守率**。

## 比較標線

按「標線 有／無 批次比較」：同一個種子各跑一次到全部離場，兩次的人（出生點、速度、要不要停）完全相同，差異只來自標線。指標：完成時間、路過者平均延遲（實際通過時間 − 無人阻礙的理想時間）、平均步行速度、擁擠指數（走路中速度 < 0.5 m/s 的比例）、最高格密度、駐足人數。單一種子可能只是運氣，用 `headless.js --seeds 5` 取平均。

## 模型

社會力模型（人與人、人與障礙的排斥）+ Dijkstra 導航場（繞過牆與障礙到達目標）。標線不是硬規定，而是改變路徑成本與駐足選位，並且只對「守規矩」的人生效。細節與限制見 `sim.js` 開頭註解。這是示意用的簡化模型，數值未經實測校準，不要當成工程設計依據。

## 檔案

- `index.html` `main.js` `style.css` — 編輯器與畫面
- `sim.js` — 模擬核心（無 DOM，瀏覽器與 Node 共用）
- `headless.js` — Node 批次執行
- `server.py` — 靜態檔案 + `scenes/*.json` 存取（標準函式庫）
- `scenes/` — 範例場景
